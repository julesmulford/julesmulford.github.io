# julesmulford.github.io

Home page and privacy policy for the **Crash-Risk Dashboard**, a personal Google Apps
Script that scores equity market risk from public data.

- Home page: <https://julesmulford.github.io/>
- Privacy policy: <https://julesmulford.github.io/privacy.html>

These pages exist to satisfy the Google OAuth consent screen requirement that an app's
home page and privacy policy be hosted on a verified domain. The application source is
kept in a separate private repository.
